# Software House Project Tracker

A full-stack web application for managing software development projects and tasks using Kanban workflow.

## Tech Stack

Frontend
- Next.js
- TypeScript
- Tailwind CSS

Backend
- Node.js
- Express.js
- TypeScript

Database
- PostgreSQL

## Features

- Project Management
- Task Management
- Kanban Board
- REST API
- User Authentication (Planned)
